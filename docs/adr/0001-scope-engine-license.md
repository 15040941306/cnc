# ADR 0001：范围、引擎、许可证和资料来源

状态：已采纳（2026-11）

## 决定

- 只做单机，不做联机。保留固定 tick、存档、回放和状态哈希，用于回归测试。
- 引擎用 Unity 2022 LTS（2022.3.x）。最初定的是 Unity 6.3 LTS，改动原因见 [ADR 0002](0002-unity-2022-lts.md)。模拟核心是纯 C#（C# 9、.NET Standard 2.1），不引用 Unity。
- 代码用 MIT，原创美术、音频、地图用 CC BY 4.0。不引入 GPL/LGPL/AGPL 依赖。
- 大模型只使用公开资料和本仓库的规格文档，不读取 OpenRA 等项目的源码。
- 美术全部重新制作，不使用原版素材作为生成或训练的输入。

见 [architecture.md](../architecture.md) §0–§2。
